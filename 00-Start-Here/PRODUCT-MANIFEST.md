# Archuleta Cyber Labs
## SOC Analyst Starter Kit v1.0

### Build It. Detect It. Investigate It. Document It.

---

## Mission

The SOC Analyst Starter Kit is a hands-on cybersecurity training
package designed to help aspiring SOC analysts move beyond
certification knowledge and develop practical security operations
experience.

Students will build a working SOC lab, generate security events,
detect suspicious activity, investigate alerts, document incidents,
and convert their work into cybersecurity portfolio projects.

---

## Target User

This kit is designed for:

- Aspiring SOC analysts
- Cybersecurity students
- Certification holders seeking hands-on experience
- Military veterans transitioning into cybersecurity
- IT professionals moving into security
- Home-lab builders
- Entry-level cybersecurity job seekers
