# SOC Analyst Starter Kit
## Lab Prerequisites

Students do not need to reproduce the exact Archuleta Cyber Labs
reference environment.

The labs are designed to teach SOC concepts that can be reproduced
using physical computers, virtual machines, or a mixed environment.

---

# Recommended Student System

## Minimum

Processor:
Modern 64-bit dual-core or better

Memory:
8 GB RAM

Storage:
50 GB available disk space

Network:
Internet connectivity and local networking capability

Operating System:
Windows 10/11 or modern Linux distribution

---

## Recommended

Processor:
Modern 4-core or better

Memory:
16 GB RAM

Storage:
100 GB or more available SSD storage

Virtualization:
Intel VT-x or AMD-V enabled

---

## Advanced Lab Environment

Students wishing to run several virtual machines simultaneously may
benefit from:

Memory:
32 GB RAM

Storage:
250 GB or more available SSD space

---

# Software Used Throughout the Course

Depending on the lab:

- Splunk Enterprise
- Linux
- Windows
- Python 3
- Web browser
- Git
- GitHub account
- Virtualization platform
- Text editor

Additional tools may be introduced within individual labs.

---

# Important

The goal is not to purchase expensive equipment.

The goal is to understand:

EVENT → LOG → DETECTION → INVESTIGATION → RESPONSE

A capable existing laptop or desktop can be enough to begin.
